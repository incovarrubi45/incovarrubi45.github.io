# INC — Israel Navon Covarrubias

Multi-page portfolio website for GitHub Pages.

Pages: Home, Work, Exhibitions, Artist Bio, Artist Statement, Résumé, Projects & Process, Contact.

Keep the `images` folder, `manifest.json`, `styles.css`, and all HTML pages together in the repository root. The site uses relative paths and works on GitHub Pages.

Before publishing, preview the pages locally and confirm all images load.
